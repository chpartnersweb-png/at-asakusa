## 開閉アニメーションの追加

- FAQ：回答欄の高さと本文の透明度・位置をGSAPで変化させる。閉じる際はアニメーションが終わってからdetailsのopenを解除する。連続操作では現在の高さから逆方向へ切り替える。展開後は高さを自動へ戻し、画面幅や文字量の変化にも追従する。
- モバイルメニュー：パネル・背景・項目を時間差で表示し、閉じる演出が完了してからdialogを閉じる。ページ内リンクはメニューの終了後に移動する。閉じるボタンとEscにも同じ処理を使用する。
- メニューボタン：開閉を1つのbutton要素に統一。二本線をGSAPで交差させて「×」へ変形し、MENU／CLOSEの文字もフェード・移動で切り替える。モーダル表示中は同じボタンをdialog内へ移し、固定位置を保つ。パネルのみをアニメーションさせるため、ボタンはパネルと一緒に移動・フェードしない。
- スクロールバー領域を確保し、メニュー開閉時の横方向のずれを抑える。動きを減らす設定では即時切り替えに対応する。

## 起動

プロジェクト指示に合わせて `npm run dev -- --background` を使用。管理は `npm run astro -- dev status`、`npm run astro -- dev logs`、`npm run astro -- dev stop`。

端末既定のNode.js管理ツールが要求バージョンを解決できない場合、この環境には次のNode.jsがインストールされている。

```powershell
$env:PATH = 'C:\Users\callt\AppData\Local\Author Software\nvm\installs\v24.22.1;' + $env:PATH
& 'C:\Users\callt\AppData\Local\Author Software\nvm\installs\v24.22.1\node.exe' 'node_modules/astro/astro.js' dev --background
```

## 公開先が決まった際の設定

`astro.config.mjs` に本番の `site` URLを設定すると、OGP画像が本番ドメインの絶対URLになる。自社予約URLは未提供のため導線は追加していない。写真の階・部屋の対応は未確認のため客室イメージとして掲載。送迎の詳細条件はLINEで問い合わせる案内にしている。

## ローディング画面

`LoadingScreen.astro`と`scripts/loading.ts`を追加。初回のページ表示時に、支給ロゴ・朱色の点・進行バーをオフホワイトの全面画面で表示する。進行状況はロゴ、メイン写真、フォント、DOMの準備完了数に基づくもので、通信バイト数の割合ではない。

通常は最低約0.7秒表示し、準備が整うと画面が上へ抜ける演出に合わせてヘッダー・メインビジュアルのアニメーションを開始。準備待ちは最大約4.2秒で切り上げ、退出演出へ進む。スキップボタンと、メインJavaScriptの取得・初期化に失敗した場合に約5.5秒で解除する独立した処理も設けた。

JavaScript無効時はローディングを表示しない。動きを減らす設定では最低表示時間と移動演出を省略し、ブラウザの「戻る」でキャッシュから復帰した場合もローディングを解除する。ローディング中はスクロールを止め、本文が操作可能になる際にLenisを再開する。
